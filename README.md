# DocForge AI — AI Document Writer SaaS

Generate professional resumes, cover letters, contracts, invoices, and SOPs instantly with AI. Pay-per-document model. No subscription required.

**Live demo:** [Deploy to Vercel in 5 minutes — see below](#deploy-in-5-minutes)

---

## What it does

Users visit your site, fill in a form, and get a polished professional document generated by Claude AI — streamed to them in real time. They pay per document using Stripe. No accounts required.

### Supported document types

| Document | Credits | Price |
|---|---|---|
| Resume / CV | 3 | $3 |
| Cover Letter | 2 | $2 |
| Contract / Agreement | 5 | $5 |
| Invoice | 2 | $2 |
| SOP / Process doc | 4 | $4 |
| Business Letter | 2 | $2 |

### Credit packs (Stripe)

| Pack | Credits | Price |
|---|---|---|
| Starter | 5 | $9 |
| Value | 15 | $19 |
| Pro | 40 | $39 |

## Tech stack

- **Backend:** Node.js + Express
- **AI:** Anthropic Claude (`claude-sonnet-4-20250514`) with streaming
- **Payments:** Stripe Checkout + Webhooks
- **Frontend:** Vanilla HTML/CSS/JS (no build step needed)
- **Hosting:** Vercel (free tier)

## Deploy in 5 minutes

### Step 1 — Get your API keys

**Anthropic API key:**
1. Go to [console.anthropic.com](https://console.anthropic.com)
2. Click **API Keys** → **Create Key**
3. Copy the key (starts with `sk-ant-...`)

**Stripe keys:**
1. Go to [dashboard.stripe.com](https://dashboard.stripe.com)
2. Click **Developers** → **API Keys**
3. Copy your **Secret key** (starts with `sk_live_...` or `sk_test_...` for testing)

### Step 2 — Create Stripe products

In your Stripe dashboard, create 3 products:

1. Go to **Products** → **Add product**
2. Create these three:

| Name | Price | Notes |
|---|---|---|
| Starter Pack | $9.00 | One time payment |
| Value Pack | $19.00 | One time payment |
| Pro Pack | $39.00 | One time payment |

3. Copy each **Price ID** (starts with `price_...`) — you'll need these in Step 4.

### Step 3 — Deploy to Vercel

**Option A: One-click (easiest)**

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Sunnyvulli/docforge-ai)

**Option B: Manual**

```bash
# Install Vercel CLI
npm install -g vercel

# Clone the repo
git clone https://github.com/Sunnyvulli/docforge-ai.git
cd docforge-ai

# Deploy
vercel
```

Follow the prompts. When asked about the framework, select **Other**.

### Step 4 — Add environment variables

In your Vercel dashboard → Project → **Settings** → **Environment Variables**, add:

```
ANTHROPIC_API_KEY       = sk-ant-your-key-here
STRIPE_SECRET_KEY       = sk_live_your-stripe-secret-key
STRIPE_WEBHOOK_SECRET   = whsec_your-webhook-secret  (get this in Step 5)
STRIPE_PRICE_STARTER    = price_xxx  (from Step 2)
STRIPE_PRICE_VALUE      = price_xxx  (from Step 2)
STRIPE_PRICE_PRO        = price_xxx  (from Step 2)
APP_URL                 = https://your-project.vercel.app
FREE_CREDITS            = 3
```

Redeploy after saving env vars: `vercel --prod`

### Step 5 — Set up Stripe Webhook

1. In Stripe dashboard → **Developers** → **Webhooks** → **Add endpoint**
2. Endpoint URL: `https://your-project.vercel.app/webhook`
3. Events to listen for: `checkout.session.completed`
4. Click **Add endpoint**
5. Copy the **Signing secret** (`whsec_...`) and add it as `STRIPE_WEBHOOK_SECRET` in Vercel

### Step 6 — Test it

1. Visit your deployed URL
2. Fill in the Resume form and click **Generate document**
3. You should see the document stream in real time
4. Click **Buy credits** → use Stripe test card `4242 4242 4242 4242` (any future date, any CVV)
5. Credits should be added after payment

## How it works

1. User visits the site → gets a **session ID** stored in localStorage
2. Each session starts with **3 free credits**
3. User fills the form and clicks **Generate** → frontend calls `/api/generate`
4. Backend checks credits → calls Anthropic API → **streams** text back via SSE
5. Credits are deducted after successful generation
6. User buys more credits → Stripe Checkout → webhook → credits added to session
7. User downloads the document as a `.txt` file

## Scaling to production

The current credit store is **in-memory** (resets on server restart). For production, swap it for a database:

**Recommended:** [Supabase](https://supabase.com) (free tier)

```js
// Replace creditStore Map with Supabase table:
// Table: sessions (id, credits, created_at, updated_at)
const { createClient } = require('@supabase/supabase-js');
const supabase = createClient(process.env.SUPABASE_URL, process.env.SUPABASE_KEY);
```

Add to your env vars:
```
SUPABASE_URL   = https://xxx.supabase.co
SUPABASE_KEY   = your-anon-key
```

## Customization

**Change pricing:** Edit `DOC_COSTS` in `server.js` and the display in `public/index.html`

**Add document types:** Add to `DOC_COSTS` in `server.js`, add a form section in `index.html`, and add a case in `buildPrompt()`

**Change free credits:** Set `FREE_CREDITS` env var (default: 3)

**Change AI model:** Edit `model` in the `anthropic.messages.stream()` call in `server.js`
